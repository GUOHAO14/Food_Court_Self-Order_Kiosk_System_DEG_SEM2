## Notes
This is a CLI Program. Why?
- the main objective of this assignment was to showcase the use of data structures and algorithms

Algorithms used:
- Kiosk Session History and Navigation --> Stack
- Incoming Orders --> Queue
- Order Distribution (to be assigned to different stalls) --> Circular Queue
- Menu Management --> Binary Search Tree (BST)

Data Structure used include static & dynamic arrays, and singly linked list (learnt doubly linked list a bit too late, lazy to implement)
